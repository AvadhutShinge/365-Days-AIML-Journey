# Day 034 - Student Performance Classification using KNN

## Objective
Build a machine learning model that predicts whether a student may pass or fail using study hours and attendance percentage.

## Topics Covered
- K-Nearest Neighbors (KNN)
- Feature scaling with StandardScaler
- Training and testing data
- Model accuracy
- Prediction probabilities

## Technologies
- Python
- NumPy
- Scikit-learn

## Installation
```bash
python -m pip install numpy scikit-learn
```

## Run the Project
```bash
python knn_classifier.py
```

Enter the student's study hours and attendance percentage when prompted.

## Note
This project uses a small, manually created sample dataset for learning only. Its accuracy and predictions are not suitable for real academic decisions.
