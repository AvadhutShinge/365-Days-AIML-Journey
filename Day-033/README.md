# Day 033 - Student Performance Prediction using Random Forest

## Objective
Build a beginner-friendly machine learning model that predicts whether a student may pass or fail using study hours and attendance.

## Topics Covered
- Random Forest Classifier
- Training and testing data
- Train-test split
- Model accuracy
- Classification report
- Making predictions for new input

## Technologies
- Python
- NumPy
- Scikit-learn

## Installation
```bash
python -m pip install numpy scikit-learn
```

## Run
```bash
python random_forest.py
```

Enter the student's study hours and attendance percentage when prompted.

## Note
This project uses a small, manually created sample dataset for learning. Its accuracy and predictions are not suitable for real academic decisions.
