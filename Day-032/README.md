# Day 032 – Student Performance Classification using Decision Tree

## Objective
Build a machine learning model that predicts whether a student may pass or fail using study hours and attendance.

## Topics Covered
- Decision Tree Classifier
- Training and testing data
- Train-test split
- Model accuracy
- Prediction for new input

## Technologies
- Python
- NumPy
- Scikit-learn

## Installation
```bash
python -m pip install numpy scikit-learn
```

## Run
```bash
python decision_tree.py
```

Enter the student's study hours and attendance percentage when prompted.

## Note
This project uses a small, manually created sample dataset for learning. Its predictions are not suitable for real academic decisions.
