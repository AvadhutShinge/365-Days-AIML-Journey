# Day 25: Python List Comprehensions and Lambda Functions

## Objective
Learn how to filter and transform data using Python list comprehensions, lambda functions, map(), and filter().

## Concepts Learned
- List comprehensions
- Lambda functions
- map() function
- filter() function
- Data filtering and transformation

## Mini Project: Data Filtering and Transformation System

This project uses student marks as a sample dataset. It removes invalid values, selects passing marks, adds bonus marks, and finds high scores.

## Features
- Remove invalid marks
- Filter passing marks
- Add bonus marks
- Find high marks
- Calculate average marks

## Technologies Used
- Python

## Learning Outcome
Learned how to filter and transform datasets using Python. These concepts are useful in AIML data preprocessing.
