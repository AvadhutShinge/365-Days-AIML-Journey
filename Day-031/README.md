# Day 031 - Student Pass/Fail Prediction using Logistic Regression

## Objective
Build a beginner-friendly machine learning model that predicts whether a student may pass or fail based on study hours.

## Topics Covered
- Logistic Regression
- Binary classification
- Model training
- Making predictions
- Prediction probabilities

## Technologies Used
- Python
- NumPy
- Scikit-learn

## Installation
```bash
python -m pip install numpy scikit-learn
```

## Run the Project
```bash
python logistic_regression.py
```

Enter the student's study hours when prompted. The program predicts PASS or FAIL and displays the estimated pass probability.

## Note
This project uses a small, manually created sample dataset for learning only. Its predictions are not suitable for real academic decisions.
