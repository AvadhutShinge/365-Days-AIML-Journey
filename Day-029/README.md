## Objective
Learn how to clean and prepare datasets for machine learning.

- Label Encoding
- One-Hot Encoding

- Train-Test Splitting

Machine Learning Data Preprocessing System

## Technologies Used
- Python
- Pandas
- NumPy

- Splits data into training and testing sets
