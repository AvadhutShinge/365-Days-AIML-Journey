# Day 030 - Student Marks Prediction System

## Objective
To predict student marks based on study hours using Linear Regression.

## Topics Covered
- Introduction to Linear Regression
- Model Training
- Model Prediction
- Data Visualization
- Scikit-learn

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn

## Project Features
- Takes study hours as input
- Predicts student marks
- Displays actual marks
- Shows a Linear Regression graph

## Conclusion
This project demonstrates how Machine Learning
can predict student marks based on study hours.
