# Day 035 - Student Performance Classification using SVM

## Objective
Build a beginner-friendly machine learning model that predicts whether a student may pass or fail using study hours and attendance percentage.

## Topics Covered
- Support Vector Machine (SVM)
- Linear kernel
- Feature scaling using StandardScaler
- Training and testing data
- Model accuracy and classification report
- Making predictions for new input

## Technologies
- Python
- NumPy
- Scikit-learn

## Installation
```bash
python -m pip install numpy scikit-learn
```

## Run
```bash
python svm_classifier.py
```

Enter the student's study hours and attendance percentage when prompted.

## Note
This project uses a small, manually created sample dataset for learning. Its predictions are not suitable for real academic decisions.
